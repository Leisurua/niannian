# 权限、隐私与数据安全

本文件集中维护安全规则；接口字段见 [OpenAPI](openapi.yaml)，实际入口为 [resource_access.py](../backend/app/platform/resource_access.py) 和各模块服务。本文描述当前实现和明确限制，不承诺未来 API 已可用。

## 身份与家庭边界

- 当前登录只接受虚构 Demo 身份。访问令牌默认 15 分钟，刷新令牌默认 7 天；每次访问检查用户和 DeviceSession，刷新轮换并检测复用。复用撤销该用户会话，不影响其他用户；退出/全部退出立即使相应会话失效。
- 刷新令牌、邀请码和设备标识保存摘要；签名密钥至少 32 字符，不提交仓库。手机号字段是预留结构，不代表真实短信登录已完成。
- 资源操作必须检查同家庭、ACTIVE 成员、主体/所有权、角色/细粒度 permission、当前 Consent 和有效资源状态。PENDING 成员可看到自己的入家状态，不能读取家庭敏感内容；邀请码和“同家庭”都不自动授予数据 scope。
- 无权枚举资源时返回与不存在一致的结果；普通客户端不能模拟 SYSTEM。客户端按钮、设备声明、唤醒词都不能替代身份验证。

## 当前权限规则

家庭创建者或 MEMBER_ADMIN 管理邀请/成员；成员读取另需相应权限。普通跨主体业务还受 CHILD/CAREGIVER 角色限制，管理员身份不替代 Consent。

| 业务 | 当前必要检查 |
| --- | --- |
| Consent 授予/撤回 | 数据主体本人发起，grantee 为同家庭 ACTIVE 成员；历史追加，按最新记录判定，不允许旧 GRANTED 复活 |
| 记忆读写 | 本人，或获 MEMORY_READ/WRITE 的家属；跨主体需记忆指定 scope。OWNER_ONLY 仅本人；候选需可写权限才能查看，不能当事实 |
| 记忆撤回/删除 | 仍校验家庭、主体与编辑权限；不要求先重新授予已撤回的数据 scope |
| 照片 | 继承关联记忆当前权限，同时检查 family、owner、文件/记忆状态；不可用文件不返回字节 |
| 生活提醒 | 本人或相应 REMINDER_READ/WRITE 家属；药物提醒写入需授权 CHILD/CAREGIVER、HEALTH_MEDICATION，老人不能自行改医嘱 |
| 提醒反馈 | 执行记录的本人；离线反馈验证 owner/family、提醒版本、发生时间、期限与幂等键，不能伪造执行或送达 |
| 会话/WSS | ACTIVE 老人本人创建文字会话，WSS 仅会话本人；连接与后续操作复查会话、令牌、家庭和设备状态 |
| 摘要 | 本人明确允许生成；指定家属需 CONVERSATION_SUMMARY、SUMMARY_READ 和 FAMILY_CHECK_IN/FOLLOW_UP 理由，读取审计 |
| 主动邀请 | 家属提议、老人确认同一版本；本人可暂停，不以通知偏好代替共同确认 |
| SignalEvent | 同家庭授权家属需 SIGNAL_READ 和 NOTIFICATION_TO_FAMILY；身体不适另需 HEALTH_MEDICATION；本人仅有限安全状态 |
| Notification | 仅指定收件人，且每次读/派发复验事件来源和当前 scope；已取消/过期/删除不可读发 |
| 设备与家庭留言 | 绑定当前登录者及其 ACTIVE 家庭，ELDER/CHILD/CAREGIVER 角色与端类型匹配；文字仅发送人和发送时确定的收件成员可读，回执仅收件本人可写。每次收发复查当前家庭成员资格；退出/撤销成员后不可继续拉取或确认 |

scope 词表保持：VOICE、PORTRAIT、FAMILY_MEMORY、HEALTH_MEDICATION、CONVERSATION_SUMMARY、CAMERA_PROXIMITY、NOTIFICATION_TO_FAMILY。通用 scope 存在不代表对应语音、相机或电话功能已实现。AI 处理另需显式授权，详见 [ai](ai.md)。

## 照片与敏感传输

桶保持私有。上传只支持校验后的 JPG/PNG/WebP，默认最多 5 MiB、1200 万像素；验证 MIME、声明尺寸、checksum 和解码结果，去除附加元数据后写独立 `.safe` 对象。客户端的原始上传签名不能覆盖安全副本。

签名默认 120 秒。下载地址是需要 Bearer 的 API 代理，每次读取重新鉴权，不返回永久公开地址或绕过撤权的 S3 直签下载。Android 只向配置的 API 同源地址发送照片凭证；原始上传在签名窗口结束后再次清理，防止迟到 PUT 重建字节。

Android API 默认 HTTPS，Debug HTTP 仅限回环/模拟器主机；局域网明文 Linux 部署不能直接作为 Android 的通用可连地址。Windows 的 HTTP 仅用于可信内网演示，公网必须 HTTPS。具体连接方法见 [deployment](deployment.md)。

真实文字 LLM 由后端单独配置，只向指定 HTTPS 基址发送 Bearer 密钥，禁止重定向；客户端不持有供应商凭证。发送前检查身份、家庭与会话，授权记忆及其历史依赖在发送前、回复发布前复验。供应商会收到用户发送的文字、短期上下文及已授权记忆；当前已接入 DeepSeek 官方 API，外部数据留存/训练政策尚未验证，联调只使用虚构数据。AI 对话的连接内历史与客户端消息只放内存，具体上限见 [AI 说明](ai.md)。家庭留言单独持久化，不送入 LLM、RAG、摘要或关注通知，也不会开启任何数据授权。

## 保留期、撤回与删除

| 数据 | 当前规则 |
| --- | --- |
| 原始音频、逐字稿 | 应用不保存录音文件，后端不接收原始音频；识别文字与回复仅在会话内存使用，设备语音服务的外部留存不由应用控制 |
| 受控摘要 | 首次允许收集主题起最长 24 小时，受授权更早到期约束；访问时先过滤，到期/撤权后台清理，不借阅读或重试续期 |
| 老人离线提醒与待同步反馈 | 最多 24 小时，按用户/家庭/提醒版本隔离；退出、切换、到期及已知撤权清理 |
| 家属照片、摘要、通知和 RAG | 不新增离线磁盘副本；Android 通知只在前台内存展示，后台/退出/换家庭/离线清空 |
| Demo/Mock SignalEvent、Notification | 从首次创建起最多 7 天，待派发通知最长 24 小时；重试、重复命中和已读不续期 |
| 待上传/隔离文件 | 默认上传声明窗口 1 小时，到期隐藏并排队清理；有效短期上传签名结束后也清理原始对象 |
| 家庭文字留言与回执 | 数据库保存人工发送的正文及成员回执，尚无自动保留期或单条删除接口；客户端已加载列表仅存内存。Android 未确认发送沿用加密会话中的待重试请求，成功或退出时清除；Windows 待重试请求仅存内存，退出后丢弃 |
| 记忆、账户、审计、task/outbox、备份 | 当前没有统一自动保留期限；不能据此宣称全账户删除、备份删除或真实数据生命周期已完成 |

撤权/删除先停止读取、检索和派发，再使 chunk/vector/cache 失效并排队清理文件及通知。清理失败期间仍不可见，任务版本和租约阻止旧 worker 恢复数据。通知按 Attempt → Notification → Signal 清理；摘要授权和通知授权独立，撤回摘要不自动取消不依赖摘要的安全通知。

完全断网时，设备无法即时知道远端撤权，直到重新联网或本地缓存到期；系统/OEM 可能延迟后台任务。已有业务行软删除不等于数据库、对象、备份的所有副本都已物理删除。全账户删除、导出、备份期限及真实供应商副本处理仍待开发，不提供虚假完成状态。

## 日志、缓存与设备

日志只允许固定错误码、脱敏编号、状态和 provider/prompt/rule 版本等元数据，不记录 token、邀请码、完整手机号、照片、健康/家庭内容、原始转写或 Provider 原始异常。审计保持业务追加，拒绝和敏感读取也审计；不开放任意审计全文 API。

Android 令牌用 Keystore 支持的安全存储，提醒 payload 加密；这不等于整个 SQLite 文件均被加密。应用自有同步启动/worker 执行边界在异常逃出前移除敏感诊断，日志 sink 失败也只能输出固定错误。该保护不覆盖未包装回调、framework/native/ANR 或 OEM 崩溃报告，不能宣称整个平台无泄漏。

Windows 令牌只存内存，设置文件仅保存服务器地址。留言正文不复制到操作日志或审计；自动刷新失败清空旧列表，换家庭、退出和令牌失效同样清理。退出先停止轮询并等待已启动请求，迟到结果不能重新填入界面。Android 留言在后台、换家庭和退出时清空已加载内容，重新进入时重新鉴权补拉。

Android 语音需要本人对自己的显式 VOICE 授权（授予家属不等价），再由前台会话按钮触发并申请麦克风权限；录音和朗读默认关闭。服务端在握手及连接循环中复验，空闲等待最多 1 秒，撤回/到期事件先于同轮回复送达，客户端收到后停止识别/朗读并拒绝旧回调；断线同样停止。系统识别和中文朗读引擎可能联网处理声音/朗读文本，界面明确提示；不承诺离线或供应商零留存。点击说话不授予家庭记忆、摘要等数据权限，也不创建声纹或克隆亲属声音。后台、结束或换家庭停止音频并清理临时内容。真实敏感数据使用前需核对所用设备语音服务的数据政策。

未来相机仅输出 presence 并丢弃帧，不识别人脸；一个音频所有者，唤醒不是认证；BLE 只能发设备事件，不能自行决定通知或紧急状态。未实现能力的当前状态见 [roadmap](roadmap.md)。

修改权限、撤回、照片、RAG 或通知可靠性时运行对应集成测试。脱敏/源码检查在 `tests/security`，具体命令见 [测试说明](../tests/README.md)；不维护重复安全矩阵或每次变更的独立验收报告。
