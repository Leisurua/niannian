# 权限、隐私与数据安全

本文件集中维护安全规则；接口字段见 [OpenAPI](openapi.yaml)，实际入口为 [resource_access.py](../backend/app/platform/resource_access.py) 和各模块服务。本文描述当前实现和明确限制，不承诺未来 API 已可用。

## 身份与家庭边界

- 当前登录只接受虚构 Demo 身份。访问令牌默认 15 分钟，刷新令牌默认 7 天；每次访问检查用户和 DeviceSession，刷新轮换并检测复用。复用撤销该用户会话，不影响其他用户；退出/全部退出立即使相应会话失效。
- 刷新令牌、邀请码和设备标识保存摘要；签名密钥至少 32 字符，不提交仓库。手机号字段是预留结构，不代表真实短信登录已完成。
- 资源操作必须检查同家庭、ACTIVE 成员、主体/所有权、角色/细粒度 permission、当前 Consent 和有效资源状态。PENDING 成员可看到自己的入家状态，不能读取家庭敏感内容；邀请码和“同家庭”都不自动授予数据 scope。
- 无权枚举资源时返回与不存在一致的结果；普通客户端不能模拟 SYSTEM。客户端按钮、设备声明、唤醒词都不能替代身份验证。

## 当前权限规则

家庭创建者或 MEMBER_ADMIN 管理邀请/成员；成员读取另需相应权限。普通跨主体业务还受 CHILD/CAREGIVER 角色限制，管理员身份不替代 Consent。

| 业务 | 当前必要检查 |
| --- | --- |
| Consent 授予/撤回 | 数据主体本人发起，grantee 为同家庭 ACTIVE 成员；历史追加，按最新记录判定，不允许旧 GRANTED 复活 |
| 记忆读写 | 本人，或获 MEMORY_READ/WRITE 的家属；跨主体需记忆指定 scope。OWNER_ONLY 仅本人；候选需可写权限才能查看，不能当事实 |
| 记忆撤回/删除 | 仍校验家庭、主体与编辑权限；不要求先重新授予已撤回的数据 scope |
| 照片 | 继承关联记忆当前权限，同时检查 family、owner、文件/记忆状态；不可用文件不返回字节 |
| 生活提醒 | 本人或相应 REMINDER_READ/WRITE 家属；药物提醒写入需授权 CHILD/CAREGIVER、HEALTH_MEDICATION，老人不能自行改医嘱 |
| 提醒反馈 | 执行记录的本人；离线反馈验证 owner/family、提醒版本、发生时间、期限与幂等键，不能伪造执行或送达 |
| 会话/WSS | ACTIVE 老人本人创建文字会话，WSS 仅会话本人；连接与后续操作复查会话、令牌、家庭和设备状态 |
| 摘要 | 本人明确允许生成；指定家属需 CONVERSATION_SUMMARY、SUMMARY_READ 和 FAMILY_CHECK_IN/FOLLOW_UP 理由，读取审计 |
| 统计与周报 | 采集需本人显式 INTERACTION_STATS；家属读取另需 REPORT_READ、指定家属的 INTERACTION_STATS 和访问理由。提醒及关注数据再次检查各自权限和 scope，不随统计授权放行。所有读取 no-store 并审计 |
| 主动邀请 | 家属提议、老人确认同一版本；本人可暂停，不以通知偏好代替共同确认 |
| SignalEvent | 同家庭授权家属需 SIGNAL_READ 和 NOTIFICATION_TO_FAMILY；身体不适另需 HEALTH_MEDICATION；确认、记录联系和解决另需 SIGNAL_WRITE，家庭创建者拥有读写权限；本人仅有限安全状态 |
| Notification | 仅指定收件人，且每次读/派发复验事件来源和当前 scope；已取消/过期/删除不可读发 |
| 设备与家庭留言 | 绑定当前登录者及其 ACTIVE 家庭，ELDER/CHILD/CAREGIVER 角色与端类型匹配；文字仅发送人和发送时确定的收件成员可读，回执仅收件本人可写。每次收发复查当前家庭成员资格；退出/撤销成员后不可继续拉取或确认 |

scope 词表保持：VOICE、PORTRAIT、FAMILY_MEMORY、HEALTH_MEDICATION、CONVERSATION_SUMMARY、CAMERA_PROXIMITY、NOTIFICATION_TO_FAMILY、INTERACTION_STATS。通用 scope 存在不代表对应语音、相机或电话功能已实现。AI 处理另需显式授权，详见 [ai](ai.md)。

## 照片与敏感传输

桶保持私有。上传只支持校验后的 JPG/PNG/WebP，默认最多 5 MiB、1200 万像素；验证 MIME、声明尺寸、checksum 和解码结果，去除附加元数据后写独立 `.safe` 对象。客户端的原始上传签名不能覆盖安全副本。

签名默认 120 秒。下载地址是需要 Bearer 的 API 代理，每次读取重新鉴权，不返回永久公开地址或绕过撤权的 S3 直签下载。Android 只向配置的 API 同源地址发送照片凭证；原始上传在签名窗口结束后再次清理，防止迟到 PUT 重建字节。

Android API 默认 HTTPS，Debug HTTP 仅限回环/模拟器主机；局域网明文 Linux 部署不能直接作为 Android 的通用可连地址。Windows 的 HTTP 仅用于可信内网演示，公网必须 HTTPS。具体连接方法见 [deployment](deployment.md)。

真实文字 LLM 由后端单独配置，只向指定 HTTPS 基址发送 Bearer 密钥，禁止重定向；客户端不持有供应商凭证。发送前检查身份、家庭与会话，授权记忆及其历史依赖在发送前、回复发布前复验。供应商会收到用户发送的文字、短期上下文及已授权记忆；当前已接入 DeepSeek 官方 API，外部数据留存/训练政策尚未验证，联调只使用虚构数据。AI 对话的连接内历史与客户端消息只放内存，具体上限见 [AI 说明](ai.md)。家庭留言单独持久化，不送入 LLM、RAG、摘要或关注通知，也不会开启任何数据授权。

## 保留期、撤回与删除

家庭记忆向量可使用服务端本地 BGE 模型计算，模型文件在部署时下载，运行时禁止联网下载；标题、正文及检索问题不发送到 Embedding 服务，也不生成输入磁盘缓存。向量仍存入同一 PostgreSQL，不提供独立读取权限。查询推理不持有家庭锁，结束后重新检查当前授权；索引写回和回复/重播仍复验源状态、版本与授权。已配置的真实聊天 LLM 仍按上节边界接收获准上下文，本地向量不改变聊天外发规则。

| 数据 | 当前规则 |
| --- | --- |
| 原始音频、逐字稿 | 应用不保存录音文件，后端不接收原始音频；识别文字与回复仅在会话内存使用，设备语音服务的外部留存不由应用控制 |
| 互动统计 | 仅从本人开启统计之后的成功轮次采集，最长 35 天并受授权更早到期约束；本人撤回立即物理删除，再次授权不恢复历史；分享撤回立即拒绝家属读取。本人可 DELETE /reports/data 清空，worker 清理过期、撤权、失效会话/家庭的数据。报告按需计算，无持久化报告副本 |
| 受控摘要 | 首次允许收集主题起最长 24 小时，受授权更早到期约束；访问时先过滤，到期/撤权后台清理，不借阅读或重试续期 |
| 老人离线提醒与待同步反馈 | 最多 24 小时，按用户/家庭/提醒版本隔离；退出、切换、到期及已知撤权清理 |
| 家属照片、摘要、通知和 RAG | 不新增离线磁盘副本；Android 通知只在前台内存展示，后台/退出/换家庭/离线清空 |
| Demo/Mock SignalEvent、Notification | 从首次创建起最多 7 天，待派发通知最长 24 小时；重试、重复命中和已读不续期 |
| 待上传/隔离文件 | 默认上传声明窗口 1 小时，到期隐藏并排队清理；有效短期上传签名结束后也清理原始对象 |
| 家庭文字留言与回执 | 数据库保存人工发送的正文及成员回执，尚无自动保留期或单条删除接口；客户端已加载列表仅存内存。Android 未确认发送沿用加密会话中的待重试请求，成功或退出时清除；Windows 待重试请求仅存内存，退出后丢弃 |
| 记忆、账户 | 记忆沿用资源撤回/删除；账户导出和删除见下节。本人业务正文物理删除，跨主体共享记录保留无姓名账户占位引用 |
| 审计、task/outbox | 审计默认 90 天，且不短于幂等窗口；原始上传已清理标记在文件仍存在期间保留。已成功任务默认 7 天；未完成/失败任务不因到期丢弃。账户删除立即清理相关审计和任务 |
| 备份 | 配置管理目录中的备份默认最长 30 天，由 worker 清理；其他目录、异地/云快照需要运维核验，期限过去不会自动宣称副本删除 |

撤权/删除先停止读取、检索和派发，再使 chunk/vector/cache 失效并排队清理文件及通知。清理失败期间仍不可见，任务版本和租约阻止旧 worker 恢复数据。通知按 Attempt → Notification → Signal 清理；摘要授权和通知授权独立，撤回摘要不自动取消不依赖摘要的安全通知。

完全断网时，设备无法即时知道远端撤权，直到重新联网或本地缓存到期；系统/OEM 可能延迟后台任务。已有业务行软删除不等于数据库、对象、备份的所有副本都已物理删除。

### 账户级生命周期

`GET /me/export` 只由本人登录调用，返回内存组装的 ZIP（`account.json` 和可用照片安全副本），响应 no-store，不在服务器保存导出副本。包含本人资料、设备、授权、记忆、提醒/反馈、受控摘要、统计、主动邀请设置、联系方式、本人事件状态、已发送留言及本人回执；不以管理员身份批量导出其他主体内容，也不导出令牌/摘要凭证、存储键、向量、供应商内部元数据或已经撤回、删除、到期的内容。默认 100 MiB、每类 10000 行，超限明确返回 413，需管理员协助；存储失败不返回不完整文件。下载文件由本人保管。

`POST /me/deletion` 只接受本人和 `DELETE_MY_ACCOUNT` 明确确认。调用方须先安全保存至少 32 随机字节生成的 `receipt_token`；服务端只保存摘要。受理事务中删除全部 DeviceSession、本人家庭成员资格/授权/联系方式，以及本人记忆、向量、提醒/执行、会话/摘要/统计、主动邀请、本人关注事件和相关通知、本人发送留言/回执、设备、邀请码和关联审计/任务。失败整笔回滚；其他主体拥有的记忆/提醒等共享记录不会因原贡献者删除而被销毁，保留无姓名账户占位引用。占位的 UUID、DELETED 状态与删除时间用于外键和防止固定 Demo 身份重新注册；不保留原姓名、手机号、设置或创建时间。

文件立即不可读。worker 等待最长上传签名窗口及余量（360 秒）后删除原件、安全副本、对象历史版本及删除标记，成功后物理删除文件行。存储权限不足或失败保持 RETRY，每分钟重试；本地完成不依赖供应商工单完成。删除回执可凭独立请求头查询，丢失首次响应可用 `/account-deletions/lookup` 找回；回执不含个人正文，不能代替登录访问任何数据。

真实 LLM/外发通知在网络调用之前持久记录可能的供应商副本，取消/超时同样需要核验；设备 VOICE 自授权记录语音服务可能留存，设备供应商未知时不承诺零留存。记录随服务配置切换保留，升级前已有账户补 `LEGACY_UNVERIFIED`，不会从当前 Mock 配置推断历史没有副本。本地清理确认前等待已授权的在途 LLM 请求结束/取消，不持有阻塞普通撤权的用户/家庭行锁；通知沿用家庭锁。供应商资源 ID、渠道和服务账号引用保留在受限运维记录，办理删除后清空，用户状态接口不暴露这些字段。供应商没有接入统一自动删除 API，运维必须核对实际供应商、账号和时间范围，向服务方办理删除并取得覆盖全部相关副本的结果凭据，使用受限服务主机上的 CLI 记录凭据摘要。受理回执或 API 资源删除成功不自动视为所有供应商副本已删除。

备份截止时间从本地清理完成起按配置计算；受理时显示预估期限。配置目录清理只覆盖约定文件，不覆盖云快照、镜像、日志归档或异地副本。运维确认全部备份副本删除或不存在后才能记录完成；超期只标记 overdue。回执仅在本地 ERASED、备份及所有供应商均有核验记录时显示 COMPLETED，仍明确保留占位/回执、其他主体共享记录、断网设备及本人下载文件的边界。最小删除记录和核验摘要持续保留用于追踪及恢复核对，不保存业务正文。操作命令及恢复要求见 [deployment](deployment.md#账户生命周期运维)。

## 日志、缓存与设备

日志只允许固定错误码、脱敏编号、状态和 provider/prompt/rule 版本等元数据，不记录 token、邀请码、完整手机号、照片、健康/家庭内容、原始转写或 Provider 原始异常。审计保持业务追加，拒绝和敏感读取也审计；不开放任意审计全文 API。

Android 令牌用 Keystore 支持的安全存储，提醒 payload 加密；这不等于整个 SQLite 文件均被加密。应用自有同步启动/worker 执行边界在异常逃出前移除敏感诊断，日志 sink 失败也只能输出固定错误。该保护不覆盖未包装回调、framework/native/ANR 或 OEM 崩溃报告，不能宣称整个平台无泄漏。

Windows 令牌只存内存，设置文件仅保存服务器地址。留言正文不复制到操作日志或审计；自动刷新失败清空旧列表，换家庭、退出和令牌失效同样清理。退出先停止轮询并等待已启动请求，迟到结果不能重新填入界面。Android 留言在后台、换家庭和退出时清空已加载内容，重新进入时重新鉴权补拉。

Android 语音需要本人对自己的显式 VOICE 授权（授予家属不等价），再由前台会话按钮触发并申请麦克风权限；录音和朗读默认关闭。服务端在握手及连接循环中复验，空闲等待最多 1 秒，撤回/到期事件先于同轮回复送达，客户端收到后停止识别/朗读并拒绝旧回调；断线同样停止。系统识别和中文朗读引擎可能联网处理声音/朗读文本，界面明确提示；不承诺离线或供应商零留存。点击说话不授予家庭记忆、摘要等数据权限，也不创建声纹或克隆亲属声音。后台、结束或换家庭停止音频并清理临时内容。真实敏感数据使用前需核对所用设备语音服务的数据政策。

未来相机仅输出 presence 并丢弃帧，不识别人脸；一个音频所有者，唤醒不是认证；BLE 只能发设备事件，不能自行决定通知或紧急状态。未实现能力的当前状态见 [roadmap](roadmap.md)。

修改权限、撤回、照片、RAG 或通知可靠性时运行对应集成测试。脱敏/源码检查在 `tests/security`，具体命令见 [测试说明](../tests/README.md)；不维护重复安全矩阵或每次变更的独立验收报告。

## THA3 本机形象

自定义形象使用本人对自己的 PORTRAIT 授权，授予家属的该项权限不能代替本人使用授权。`AvatarModel` 在前台每 15 秒发起一次现有 `/consents` 查询；每次确认的有效展示期不超过请求开始后的 30 秒，并受授权自身到期时间限制。查询失败或展示期届满即隐藏自定义形象，返回前台、导入时重新核对。确认撤回或到期后删除本机副本；重新授权产生的新授权 ID 不能重新启用旧授权的缓存。它不使用语音 WSS 的秒级撤权事件。

角色包仅存老人端 `noBackupFilesDir`，使用 Android Keystore AES-GCM 加密，附加认证数据绑定应用、家庭、本人和具体授权 ID。退出登录、令牌清理、切换家庭及应用现有缓存失效回调销毁密钥并删除文件。后台清除已加载角色和取消导入，返回后需重新验证；取消、删除和切换主体使迟到结果失效。断网时不展示旧角色，尚无法查询到撤权的加密副本会在恢复验证后清理。

ZIP 不解压到用户指定路径，只接受固定名称的四张 PNG 图集和清单；拒绝额外/重复文件、路径穿越、超限字节数、图块数量和图片尺寸。导入前解析 PNG，失败保留原有效形象。角色包包含归属说明，模型权重不进入 APK。用户选择器中的原照片/ZIP、制作电脑上的立绘和导出包不属于应用私有副本，需由持有人自行删除。本机外观不改变 AI 身份：界面仍持续显示“念念 AI 陪伴”。

手机照片制作仅限当前家庭的长辈本人操作，需本人 PORTRAIT 授权，并在所选照片预览中再次确认具体处理服务。请求绑定授权 ID、服务地址/模型指纹、声明大小和 SHA-256；改变服务或授权后旧任务不得外发/发布。手机整理方向、缩小图像并移除元数据，服务端再次验证和清理。源照片仅短期签名 PUT 到私有存储，下载包和预览每次重新鉴权且 no-store，不能用家庭照片接口访问未绑定记忆的资源。千问返回图像只允许下载其 OSS HTTPS 域名，不转发 API 密钥或跟随跳转。

任务生成完成先 READY，需本人下载预览并提交同一包的摘要才能 ACTIVE。原始上传删除、清理后的源照片生成完成即排队清理；未确认任务 24 小时到期。已启用包保留到取消、撤回授权或账户删除。授权更新/撤回立即取消旧任务，后台心跳和各阶段写回复验；迟到结果不得发布。已提交供应商的请求无法追回，可能副本记录在发送前持久化，删除核验沿用账户生命周期规则。服务端通过内存管道执行抠图/GPU 推理，不保存中间立绘文件。

取消/到期资源先不可读，再由普通 worker 删除私有对象与版本；签名 PUT 的原始上传窗口关闭后才完成最终清理，避免迟到上传留下文件。账户删除与外发/写入协调后清理任务和所有角色资源；本人导出包含仍可访问的任务与角色资源，不包含已清理的源照片。手机后台、断网或切换主体清除未确认照片和预览，回前台重新查询授权与进度；不自动重发照片。

## 关注事件联系与外发

紧急联系人只扩展 SIGNAL_READ/SIGNAL_WRITE 的可授权角色，不获得其他业务权限；仍逐次检查长辈关注/健康授权。号码仅由成员本人登记，share_phone 默认关闭，仅事件处理人可读取当前允许分享的长辈/已获授权紧急联系人号码。号码和 ntfy 主题加密落库，不进入日志或审计正文，删除联系人/退出/移除成员后不可再使用。号码暂为本人声明，未验证运营商归属。

外发默认关闭，demo/test 禁止启用真实渠道；用户还需选择接收渠道。发送前在家庭锁内再次检查授权、偏好、事件状态，网络调用限制 5 秒；撤回与发送按此锁串行，撤回不能追回此前已提交供应商的通知。仅发送通用 AI 提示。ntfy 主题须配置私有访问控制。短信送达和电话结束不代表事件解决，均不能自动产生家属处理动作。

周报页面仅驻留内存：Android 后台/换家庭/读取失败清空，打开时每 30 秒重新检查；Windows 离开页面、失去窗口焦点、换家庭/账户或展示 30 秒后清空。天气后端只接收公共城市编号，从 Open-Meteo 城市目录取得公共坐标，不接收设备经纬度，也不向天气供应商发送登录凭证。
