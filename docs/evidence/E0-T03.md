## Implemented

- Backend JSON records allow stable event codes and the documented request, correlation, entity, provider, latency, result, and error-code fields. Message text, exception text, extra fields, unknown logger names, and unexpected level names are excluded.
- Identifier validation rejects full-phone and common credential shapes. HTTP request IDs use the same validator before entering response and logging context.
- Uvicorn loggers use the redacted formatter. Uncaught main-process and worker-thread exceptions emit a generic structured crash event without a traceback or exception message.
- Android telemetry retains allowlisted fields and rejects phone- and credential-shaped metadata.

## Repair investigation — 2026-09-30

Repair is BLOCKED pending review of the [Android crash privacy repair proposal](E0-T03-repair-proposal.md). Android 12's runtime pre-handler logs the original exception before an app's default uncaught handler runs; the earlier replacement hooks are restricted for the current target SDK. A default-handler-only patch would not close E0-T03-LOG-001. The proposal records official source evidence, alternatives and the required review; it is not an accepted contract change. No production code or probe was changed and no device rerun occurred. PRIV-002 and the combined gate remain FAIL; all earlier evidence is retained.
