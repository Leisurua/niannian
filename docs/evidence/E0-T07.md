# E0-T07 Adapter Protocols and Deterministic Mocks

## Dependency

`E0-T01` is marked PASS in `docs/development-checklist.md`; the backend package,
test layout, and empty integrations package were present before this task.

## Scope and acceptance

- Added provider-neutral DTOs and Protocols for ASR, LLM, Embedding, TTS,
  Avatar, WakeWord, Push, and Weather in `backend/app/integrations/contracts.py`.
- Added deterministic implementations under `backend/app/integrations/mock/`.
  Each adapter declares `provider=mock` in its capabilities; result DTOs that
  carry a provider field also report `mock`.
- MockASR does not decode or retain audio. MockLLM emits fixed non-factual
  output without Memory or Signal candidates. MockTTS supplies a text fallback.
  MockPush never reports observed delivery; MockWeather reports no live weather.
  MockWakeWord emits no event unless a test explicitly supplies one.
- No real provider SDK, API/WSS, database, or public enum was changed.
