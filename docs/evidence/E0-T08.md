## Fixture and replay

- `scripts/demo_seed.py` defines 24 fixed UUIDv7 rows in the `DEMO_DATA:E0-T08` namespace. Elder and child users have no phone fields. Family display name is visibly fictional. No photo, audio, transcript, contact number, credential, or real provider output is included.
- Rows cover active members; granted and revoked Consent; confirmed, pending, and revoked Memory; DONE and NO_RESPONSE reminder executions; notified, withheld, and failed SignalEvents; read in-app and failed Mock push notifications; and READY/FAILED WeeklyReport with missing-data text.
- `scripts/seed_demo_data.py --check` validates the fixture without writing. `--apply` requires explicit demo/fictional/Mock environment settings and a database URL. It checks the existing table/column inventory and namespace ownership, then deletes only fixed demo row IDs in reverse dependency order and reinserts them in one transaction. It creates no table or migration.
