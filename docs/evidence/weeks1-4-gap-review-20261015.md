## Decisions

按以下口径理解“完成”：

| 类型 | 判断方式 |
| --- | --- |
| 软件范围完成 | 相应代码已实现，限定范围的测试已实际运行并通过 |
| 待验收 | 软件已有实现，但指定设备或真实操作场景缺少完整证据，保留 `NOT VERIFIED` |
| 部分实现 | 已交付子路径，但任务完整依赖或验收条件尚未满足 |
| 跨周依赖 | 依赖后续业务表、模块或审批门禁，不能为了关闭早期清单擅自扩大本周范围 |

此前“第四周完成”应理解为 **Mock 软件子范围完成**，不能据此将完整 `E4-T03`、真实语音或完整 VS-03 闭环标为完成。

不按清单勾选数量计算完成百分比：现有记录包含历史快照、跨周依赖和不同粒度的任务，直接相加会失真。
