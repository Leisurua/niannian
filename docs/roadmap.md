# 当前进度与待开发功能

以本次代码为准，本文只维护有效待办，不再按周创建计划/验收文件。产品目标见 [需求说明](../nian-nian-requirements-design.md)，运行入口见 [deployment](deployment.md)。

## 已实现

| 范围 | 实际能力 |
| --- | --- |
| 后端 | Demo 登录/刷新/退出、家庭邀请和成员、分项授权/撤回；记忆/照片；提醒及幂等反馈；本人文字会话、授权 RAG、受控摘要、在线主动邀请；规则警告、非紧急事件与 IN_APP/Mock 通知 |
| Android | 老人/家属两个应用；共享会话/网络/业务库；老人提醒加密缓存和待同步反馈；家属获准内容与前台通知 |
| Windows | 两个演示界面、共用 HTTP/鉴权/后台任务；当前后端只支持其登录、家庭与邀请 |
| Linux | 同一后端的 API、worker、迁移、PostgreSQL/pgvector 和私有 MinIO Compose 部署 |

当前 OpenAPI 只列实际提供的 REST 操作，数据库文档只列已迁移的表。语音、消息、硬件等目标不因存在 DTO、枚举或测试替身而算完成。

## 接下来按功能推进

| 方向 | 待完成内容 / 当前限制 |
| --- | --- |
| 真实语音与 AI | 选择可用 LLM/ASR/TTS，完成录音、识别、流式编排、打断、播放和文本降级；当前全部为 Mock，先确认真实数据的供应商留存/训练策略 |
| 家庭通信与联机 | Windows 留言/设备注册及回执后端、Android/Windows 跨设备联调；目前 `/devices`、`/messages` 未提供；Windows 令牌到期需重新登录，刷新/退出待联调 |
| 家属响应 | 关注事件的确认、联系、误报、解决与通知动作；当前只有读取、已读和偏好，不能宣称处理闭环完成 |
| 生活内容与周报 | 真实天气、统计/周报及缺失数据解释；不把无反馈解释为未服药，不由模型改医嘱 |
| 隐私生命周期 | 账户级删除/导出、审计/任务/备份期限、供应商副本删除及断网后的清理结果；当前资源级撤回不等于全账户副本全部删除 |
| 真实通知与紧急联系 | 选用实际渠道、验证送达/失败；实现联系人和电话闭环，区分发起、振铃、接通、未接和失败。当前只有 Mock 派发和本地求助提示 |

## 设备化目标

kiosk/开机恢复、BLE 按钮、离线唤醒、CameraX presence、电话/OEM 兼容均未作为当前可用能力。先在指定设备观察实际权限/连接/失败，再决定 SDK 和实现；失败保留普通 App、点击/文字等入口。相机不保留帧或识别人，唤醒不作身份认证，设备事件不直接决定通知和紧急状态。

没有新增每周报告、审批流水线或归档目录。一次功能修改只同步受影响文档和必要测试，不以测试数量、Mock 结果或构建成功替代真实功能证据。
