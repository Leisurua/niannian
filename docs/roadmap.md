## 已实现

| 范围 | 实际能力 |
| --- | --- |
| 后端 | Demo 登录/刷新/退出、家庭邀请和成员、分项授权/撤回；记忆/照片；提醒及幂等反馈；本人文字会话、授权 RAG、受控摘要、在线主动邀请；规则警告、非紧急事件与 IN_APP/Mock 通知；设备注册、家庭文字留言及幂等接收/已读回执 |
| Android | 老人/家属两个应用；共享会话/网络/业务库；老人提醒加密缓存和待同步反馈；家属获准内容与前台通知；家庭留言收发、前台同步及已读确认 |

| Linux | 同一后端的 API、worker、迁移、PostgreSQL/pgvector 和私有 MinIO Compose 部署 |

当前 OpenAPI 只列实际提供的 REST 操作，数据库文档只列已迁移的表。语音、消息、硬件等目标不因存在 DTO、枚举或测试替身而算完成。

## 设备化目标

kiosk/开机恢复、BLE 按钮、离线唤醒、CameraX presence、电话/OEM 兼容均未作为当前可用能力。先在指定设备观察实际权限/连接/失败，再决定 SDK 和实现；失败保留普通 App、点击/文字等入口。相机不保留帧或识别人，唤醒不作身份认证，设备事件不直接决定通知和紧急状态。

没有新增每周报告、审批流水线或归档目录。一次功能修改只同步受影响文档和必要测试，不以测试数量、Mock 结果或构建成功替代真实功能证据。
