| 顺序 | 工作及负责人 | 完成时应能观察到的结果 |

## 详细工作分工

以下按当前代码拆分实际工作。**待验证**表示已有实现，需要在指定设备、供应商或部署环境操作；**待补齐**表示已有部分能力，仍需修改代码；**待开发**表示当前没有可用实现。一个任务可同时包含补齐和验证，不能因存在接口或构建成功标记完成。

这些任务覆盖既定比赛原型范围；轻量游戏、紧急联系及指定平板设备化仍是原型要求，后排执行不表示降为可选。照片制作的第二供应商验证不阻塞默认数字人交付。原声家庭留言、视频通话和照片动态流不在本轮新增工作内。

### A：后端业务、数据库与通知

主要入口：[业务模块](../backend/app/modules/)、[后台任务](../backend/app/worker/)、[数据库说明](database.md)。A 负责业务状态和权限，B 提供候选，C/D 接入客户端。

1. **A1 家庭与分项授权联调｜待验证，配合 C/D。** 沿用现有 Demo 登录、刷新、退出、邀请确认和角色权限，用虚构账户走通家庭创建、加入、成员切换与授权撤回。检查家庭记忆、语音、摘要、通知、健康信息、互动统计等独立授权，修复客户端与服务端状态不一致。完成表现：加入家庭不自动开放敏感数据，跨家庭和撤权后的访问被拒绝，刷新或重新登录不会恢复旧权限。

2. **A2 家属处理闭环｜待验证，配合 C。** 沿用关注事件确认、人工联系、误报、解决、历史及移动收件箱实现，检查并发处理、重复提交、当前授权和处理权限；确认误报/解决会取消待发通知，老人端可读取本人处理进度。完成表现：家属提交一次动作只产生一次有效处理，另一端刷新能看到操作者、时间和实际状态；人工记录联系不冒充平台验证接通。

3. **A3 真实外部通知｜待真机验证，配合 C/D。** 本地免费私有 ntfy 已完成 HTTPS 发布订阅与权限隔离，秒级派发、通知点击直达及订阅入口已有实现；继续检查指定手机的锁屏送达、账号/授权核验和失败展示。Twilio 实际送达仍未验证，号码目前为本人声明。外发默认关闭，供应商受理、实际送达、失败和结果未知分别展示，未知结果不自动重复短信或呼叫。渠道配置及具体状态含义统一见 [部署说明](deployment.md#外部关注通知默认关闭)。

4. **A4 紧急联系业务｜待补齐，配合 B/C/D。** 当前联系人、家属侧系统拨号入口和外发适配已具备，老人主动求助、语音入口及实体按钮尚未形成完整联系闭环。补齐明确求助的业务入口、必要持久状态、重复请求去重及家属可见进度，复用现有联系人与通知服务。完成表现：老人主动求助后能进入实际联系流程，失败和无可用联系人有提示；只有平台提供可靠证据时显示接通/未接，否则显示未知，不把非紧急关注候选直接升级为紧急事件。

5. **A5 提醒与生活查询｜已接入，待真机验证，配合 B/C。** 日期、当天预报及本人当日提醒已接入会话确定性查询，完成/稍后反馈复用执行记录和幂等服务，Android 成功后刷新提醒缓存；天气沿用手选城市，不自行推断位置。继续在指定真机核查家属设定后老人收到、语音反馈、稍后通知与离线重复同步；无反馈只显示“尚未收到反馈”，模型不能改医嘱。协议与使用范围见 [AI 说明](ai.md)。

6. **A6 统计与周报数据｜待验证，配合 B/C/D。** 保留现有最小指标、日期范围统计和实时固定模板周报，核对本周/上周、时区、空数据、授权范围、Mock 轮次和本人统计删除；B 扩展分类时仅调整必要数据字段与调用方。完成表现：双端展示同一口径，缺失数据有说明，撤回统计授权后停止采集及访问，不用模型生成不存在的统计结果。

7. **A7 账户隐私生命周期｜待补齐及验证，配合 B/C/D。** 后端导出、账户删除、独立回执查询/找回、对象版本清理和重试已有实现，向 C/D 提供现有接口完成界面接入；与 D 核验实际备份覆盖，与 B 核验供应商副本办理。完成表现：本人可以发起导出或删除并查询进度；本地擦除、供应商和备份核验分别有实际结果，未核验不显示全部完成。保留期限和无法远程即时擦除的边界统一见 [安全说明](security.md#账户级生命周期)。

### B：AI、语音编排与记忆检索

主要入口：[会话编排](../backend/app/ai/conversation.py)、[集成实现](../backend/app/integrations/)、[记忆检索](../backend/app/modules/memory/rag.py)、[AI 说明](ai.md)。设备 ASR/TTS 的 Android 实现由 C 维护，B 负责与会话协议和业务衔接。

1. **B1 真实 LLM 连续交流｜待验证，配合 C/D。** 在指定真机连接当前真实 LLM/WSS，验证多轮上下文、首次响应与后续等待时间、超时、非法输出、断网重连和取消。完成表现：可连续交流，失败后能编辑输入重试，重连不自动重发；真实/Mock 标识与服务器握手一致，日志只保留必要脱敏元数据。

2. **B2 语音协议与控制指令｜待补齐及验证，配合 C。** 先验证已有系统 ASR → 文字 WSS → LLM → 系统 TTS，保留按钮打断；让识别出的“再说一遍”“慢一点”等控制语句进入确定性控制逻辑，核对“今天少打扰我”已有服务端处理。“停一下”的收音条件与播放控制需和 C 的音频占用统一，不把按钮打断当作持续监听已完成。完成表现：支持已约定控制命令、拒绝权限和服务失败的文字降级，取消后旧轮次与迟到设备回调不继续播放；重播仍重新校验记忆权限。

3. **B3 家庭记忆端到端检索｜待验证，配合 A/C。** 本地 BGE、模型指纹隔离、获准子集检索、旧索引补建及推理中撤权已有真实模型/pgvector 验证。继续用手机完成家属录入、人工确认、老人同义提问、无匹配、纠错和撤回，并检查实际回答的来源。完成表现：只引用当前获准且确认的记录，无依据时说明不确定，撤权后当前回复、重播和后续上下文都不继续引用。

4. **B4 关注线索与诈骗辅助理解｜待场景验证，配合 A/C。** 身体不适、情绪、往事/偏好和思念/联系意愿已接入同次真实 LLM 回答中的结构化候选，原文依据、来源、类别和授权由代码复验；七条虚构正反例已通过真实服务。继续结合手机识别文本检查误报和漏报。诈骗组合和明确求助仍由确定性规则优先处理，模型不能决定收件人、敏感动作或紧急状态。普通语义线索不自动变成已确认记忆。

5. **B5 日期、天气与提醒对话｜已接入，待真机验证，配合 A/C。** 语音识别文字已接入服务端时钟、手选城市当天预报和本人当日提醒，查询绕过 LLM/RAG、标注来源；明确反馈由确定性代码保存。继续核查指定手机的实际识别、播报、断网和提醒触发。当前支持范围、歧义处理和默认延后时间统一见 [AI 说明](ai.md)。

6. **B6 主动陪伴与受控回顾｜待验证及补齐，配合 A/C。** 核对家属提议、老人确认、时间窗、频率、免打扰、当日暂停和当前会话摘要。主动邀请目前为在线 Mock 文字，需补齐真实陪伴演示中的邀请衔接，并明确在线邀请与后台提醒的能力边界。完成表现：有效设置下出现邀请，老人拒绝后不继续打扰；只有本人明确进入语音交互才启动相应音频，家属只能按授权和理由读取受控摘要。

7. **B7 周报语义分类｜待补齐及验证，配合 A/C。** 周报现有情绪与重复主题为有限本地分类，继续补齐同义表达和跨会话相似主题识别，复用已有本地 embedding 能力，不保存逐字稿。完成表现：重复主题统计可解释，能区分否定、转述与本人表达，无数据不下结论，始终标注交流观察线索，不输出医疗结论。

8. **B8 自定义形象服务联调｜待验证，配合 C/D。** 豆包真实图生图、抠图和 GPU THA3 已有验证，继续检查手机照片授权、制作任务、失败取消、资源下载和确认启用；若演示使用千问，再完成该供应商真实调用。完成表现：手机制作能得到可用四态包并由本人预览确认，失败不自动重复付费请求；默认形象可独立交付，无需音素级口型或手机端实时 THA3。

### C：Android 老人端、家属端与指定平板

主要入口：[老人应用](../android/app-elder/)、[家属应用](../android/app-family/)、[共享功能](../android/shared/src/main/java/org/example/niannian/feature/)。沿用现有三个 Gradle 模块，不另建一套客户端业务。

1. **C1 家庭入口与首次使用｜待验证及补齐，配合 A/B。** 走通登录、家庭绑定、成员选择、分项授权、联系人配置和撤回，核对首次完整 AI 身份/隐私说明与每次新会话短提示。完成表现：大字和关键按钮可操作，未开放的敏感项不阻塞基础文字交流，真实 LLM、设备语音和 Mock 文案准确，不冒充真实家属。

2. **C2 真机语音交流｜待验证及补齐，配合 B/D。** 检查指定设备的识别服务、中文 TTS、麦克风权限和 VOICE 自授权，完善识别、等待、播放、取消、重播、慢速和文字降级；接入 B2 的已识别控制指令。完成表现：完成一次“说话—识别—真实回答—播音—打断—继续—结束”，后台、断网、换家庭和撤权均停止音频；记录实际等待和失败原因，修复现场阻塞。

3. **C3 数字人与手机照片制作｜待验证，配合 B/D。** 默认柿子、四态展示、THA3 本机导入、手机上传制作、预览及确认启用已有代码。验证倾听/思考/实际播音/停止的状态一致性，检查制作失败、取消、切换家庭和 PORTRAIT 撤权。完成表现：默认形象可完成真实陪伴演示；自定义包能安全下载、无声预览并确认使用，停止后口型立即停止，失败不破坏已有可用形象。

4. **C4 家属通知与老人进度｜待真机验证，配合 A/B。** 已接入私有 ntfy 订阅入口和通知直达；验证关闭界面/锁屏后的实际推送、冷启动点击、账号核对、重新鉴权、事件处理和老人端进度。JobScheduler 最短 15 分钟的定期收件保留为补拉，及时通道由 ntfy 订阅接收；省电、断网和关闭订阅仍影响送达，不承担紧急保证。完成表现：手机实际出现通用提示，点击进入正确获准事件，处理后双端同步；拨号/短信编辑器与人工确认保持明确区别。

5. **C5 提醒、留言、天气和周报｜待验证及补齐，配合 A/B/D。** 核对首页实际数据、提醒管理与反馈、离线重启补同步、家庭文字留言及已读确认、手选城市天气和最近四周报告；接入生活查询与需要的语音反馈。完成表现：服务端保存成功后才提示成功，重复反馈/发送不重复落库，收到留言不自动算已读，空数据/断网/授权不足有可操作提示。

6. **C6 账户数据管理界面｜待开发，配合 A。** 接入现有本人导出、账户删除和独立删除回执接口，提供影响说明、二次确认、处理中/失败/完成状态及首次响应丢失后的找回。完成表现：本人在手机上可完成完整操作，删除后清理本端会话和私有缓存，仍能用独立凭证查询删除进度；不将本地清理写成全部供应商和备份已删除。

7. **C7 轻量认知游戏与回忆引导｜待开发，配合 B。** 完成需求中的轻量游戏，优先做一个有开始、退出、重试的完整玩法，再用当前获准家庭记忆提供回忆引导。完成表现：大按钮、文字/语音提示可用，随时退出后恢复普通交流；没有授权时提供通用内容，不把游戏表现解释为诊断，也不新增无必要的长期成绩系统。

8. **C8 kiosk 与开机恢复｜待开发，配合 D。** 在指定平板核查设备管理员条件，实现并配置单应用锁定、开机进入老人端和必要故障恢复；已有开机广播权限或设备状态字段不算完成。完成表现：指定平板重启后可进入老人端，普通用户按既定模式无法退出到桌面；权限不足明确显示配置失败，保留普通 App 运行方式。

9. **C9 离线唤醒与离线提醒播报｜待开发及补齐，配合 B/D。** 根据指定设备选择成熟离线唤醒能力，与 ASR/TTS 共用音频占用；现有离线提醒缓存/反馈继续复用，补齐实际离线播报所需的本地中文语音。完成表现：断网能唤醒并播报有效缓存提醒，联网模型不可用时明确提示；没有离线引擎或权限时保留点击、文字和系统通知，不伪造回答。

10. **C10 人员接近唤醒｜待开发，配合 D。** 集成 CameraX 等现有设备能力，仅检测有人靠近且持续达到设定条件，控制唤醒频率；处理摄像头拒绝、被占用和退后台。完成表现：指定平板有人靠近时可唤醒界面，关闭后停止检测；不识别人、不保存画面或生物特征，不以检测结果决定授权和紧急状态。

11. **C11 BLE 实体呼叫按钮｜待开发，配合 A/D。** 确认指定按钮协议，完成配对、连接、按键事件去重、断连重连和权限提示；先依赖 A4 的实际联系入口，再接入按钮。完成表现：按下后本机立即显示状态并进入同一联系流程，重复设备事件不重复呼叫；断连、低电量（硬件提供时）及权限不足显示实际状态，按钮事件本身不决定业务权限。

## 连续演示与工作完成判断

最终演示使用虚构资料，在指定 Android 真机、Windows 与同一 Linux 后端串联：

1. 家属建家并邀请，老人确认加入、查看 AI 身份和隐私说明，分别选择数据授权及联系人。
2. 家属录入并确认家庭记忆/照片，老人用语音同义提问，真实 LLM 基于获准来源回答并驱动数字人；演示打断、重播和结束。
3. 老人询问实际日期/天气/安排，收到提醒并反馈；断网重启后反馈仍能在恢复连接时幂等同步。
4. 用虚构身体不适、思念或风险组合触发关注提示，家属在指定渠道实际收通知、打开并确认/联系/解决，老人看到处理进度。
5. 展示固定模板周报、互动时段与相似主题观察，完成一个轻量游戏及退出；不展示虚构健康结论。
6. Windows 与 Android 互发家庭文字留言并确认已读；不把消息接收当成人已阅读。
7. 指定平板演示开机进入、kiosk、离线唤醒、人员接近唤醒和 BLE 求助；联系结果仅展示平台实际可确认的状态。
8. 撤回一条记忆/照片授权后重新提问并验证旧内容不可引用，再展示本人导出及删除进度；未完成的外部清理仍显示未完成。

每项开发只运行关联测试和必要构建；涉及公共调用、迁移、权限、撤权和幂等时按 [测试说明](../tests/README.md) 验证受影响范围。已有 2026-10-20 实机记录仅覆盖其列明项目，本次工作拆分没有新增真机、供应商或部署通过结论。没有新增每周报告、审批流水线或归档目录。
