# 念念 Windows 老人演示端 0.1.0

这是用于课堂演示四端通信链路的 Windows 老人端。它不是穿戴设备、医疗器械或真实紧急呼叫终端。

## 已实现

- 大字号、低层级老人端界面；
- TCP 与 `/health` 连接检查；
- `demo-elder` 演示登录；
- 接受子女端生成的家庭邀请；
- 注册为 `ELDER_MOBILE`；
- 每 3 秒轮询家人留言并自动发送 `RECEIVED` 回执；
- 老人主动点击后发送 `READ` 回执；
- “我很好”“我已看到”“请给我打电话”三个快速回复；
- 普通和重要留言的视觉区分。

“请给我打电话”是 `IMPORTANT` 文本消息，不是 SOS，不代表已经拨通电话。当前服务端尚未实现可供本演示端调用的真实紧急呼叫闭环。

访问令牌只存在进程内存中。本地仅在 `%APPDATA%\NianNianElderDemo\settings.json` 保存服务器根地址。

## 使用顺序

1. 子女端登录并创建家庭；
2. 子女端生成老人端邀请令牌；
3. 老人端登录，粘贴并接受邀请；
4. 老人端选择家庭，点击“启用这台老人端”；
5. 子女端也注册设备并发送留言；
6. 老人端自动接收，点击“我已读完这条”；
7. 子女端刷新发件箱，确认状态为 `READ`；
8. 老人端点击快速回复，子女端刷新收件箱。

## 开发运行与构建

```powershell
.\run-dev.ps1
.\build.ps1
```

构建产物位于 `dist\念念-Windows老人演示端.exe`。

Windows 当前仍无法访问 Kali NAT 地址 `192.168.193.128:8000`。真实联机前应先恢复 VMware `VMnet8`、配置 NAT 端口转发，或切换桥接网络；具体判断以 `Test-NetConnection` 的结果为准。
